## Project Overview

Developed custom healthcare service pages for Lifecare Diagnostics using WordPress, PHP, and third-party API integration.

The project involved creating a custom WordPress plugin to retrieve and display healthcare information dynamically, including Health Packages, All Tests, and Test List pages.

The implementation focused on integrating external diagnostic service data into a structured, user-friendly WordPress interface.
